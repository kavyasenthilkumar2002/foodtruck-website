🍔 FoodTruck – Modern Food Truck Website

A modern, responsive, and user-friendly food truck website built with React.js, Tailwind CSS, and Vite. The project showcases a complete food truck brand experience with menu exploration, interactive UI elements, and customer contact functionality.

📌 Project Overview

FoodTruck is designed to simulate a real-world food truck business website where customers can:

Explore food categories and menu items
Search and filter dishes
Learn about the brand story
Contact the business through a validated contact form
Experience a smooth and responsive user interface

The goal of this project was to build a product-like frontend application while focusing on performance, usability, and modern UI/UX practices.

Install Dependencies

Start Development Server
