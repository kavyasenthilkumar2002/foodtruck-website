# FoodTruck Website
A modern and responsive FoodTruck website built using React and Tailwind CSS.

## Features
- Responsive Design
- Modern UI/UX
- Food Menu Section
- About Us Section
- Contact Form
- Fast and User-Friendly Interface

## Technologies Used
- React.js
- Tailwind CSS
- JavaScript
- Vite
